# 5. Comments

| Type                | Symbol    | Example                      |
|---------------------|-----------|------------------------------|
| Single-line comment | `#`       | `# This is cool`             |
| Multi-line comment  | `''' '''` | `''' This is cool omg '''`   |

- A `#` comment runs to the end of the line
- Python ignores comments when the code runs
- `''' '''` isn't technically a comment. It's a multi-line string that nothing uses, so Python skips it. `""" """` works the same way.
